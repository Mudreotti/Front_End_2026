# Meu Pet Jelly 🐾

Projeto interativo desenvolvido como prática de HTML, CSS e JavaScript.

## Funcionalidades

- Alimentar o personagem e acompanhar a barra de fome.
- Alterar a aparência do personagem conforme seu estado.
- Alternar entre os modos de dia e noite automaticamente ou pelo botão de clima.
- Abrir e fechar uma sobreposição com uma foto secreta.
- Utilizar imagens locais para o personagem, o cenário e os botões.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta `Pokemon`.
3. Abra o arquivo `index.html` em um navegador moderno.

Não é necessário instalar dependências ou executar um servidor para a versão atual.

## Estrutura dos arquivos

- `index.html`: estrutura da página e estilos CSS.
- `script.js`: interações, temporizadores e estados do personagem.
- `b_*.png`: imagens dos estados do personagem.
- `bg.png`: imagem de fundo.
- `btn.png`: imagem do botão de alimentação.
- `image_9.png`: imagem exibida na sobreposição.

## Tecnologias

- HTML5
- CSS3
- JavaScript
