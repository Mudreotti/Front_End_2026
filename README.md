# Front-end 2026

Repositório de estudos e atividades práticas de desenvolvimento front-end, reunindo exercícios acadêmicos e pequenos projetos feitos durante meu aprendizado.

## 📌 Projetos em destaque

### 🐾 Meu Pet Jelly
Um projeto interativo desenvolvido com HTML, CSS e JavaScript. O usuário pode alimentar o personagem, acompanhar sua barra de fome, alternar o clima entre dia e noite e abrir uma foto secreta.

- **Código:** [pasta Pokemon](./Pokemon/)
- **Como executar:** abra o arquivo [index.html](./Pokemon/index.html) em um navegador.
- **Tecnologias:** HTML, CSS e JavaScript.

### ❌ Jogo da velha
Exercício de lógica com tabuleiro 3×3, alternância entre X e O, identificação de vitória ou empate e opção de reiniciar a partida.

- **Arquivo atual:** [Jogo da velha](./Jogo%20da%20velha)
- **Observação:** o conteúdo está registrado em um único arquivo de estudo, com trechos de HTML, CSS e JavaScript. A separação em arquivos próprios ficará para uma próxima etapa.
